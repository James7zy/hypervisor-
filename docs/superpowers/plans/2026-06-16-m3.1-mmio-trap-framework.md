# M3.1 — MMIO Trap-and-Emulate Framework (Stage-2 data-abort decode + device bus) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the M3.0 stall (an EC `0x24` data abort hitting the `default` `wfi` case in `handle_exit`) with a real Stage-2 data-abort decode + MMIO trap-and-emulate dispatch path. A trapped guest load/store must reach a registered device handler with the correct **address, size, direction, and data**, after which the hypervisor advances `ELR_EL2` past the faulting instruction and erets back to the guest. The definition of done is observable on `make run`: a temporary scaffold device registered over the GICD range prints the decoded `{addr,size,dir,data}` for the guest's first GIC accesses, and the guest keeps running past the first access instead of parking.

**Architecture:** On EC `0x24` (Data Abort from a lower EL), `handle_exit` calls a new `mmio_handle_data_abort(regs, esr)`. That function:
1. Reads `HPFAR_EL2` (faulting IPA page) + `FAR_EL2` (page offset) to reconstruct the faulting **IPA**. (When Stage-2 is on, `FAR_EL2` holds the guest VA; the IPA is in `HPFAR_EL2`.)
2. Decodes the ESR_EL2 ISS for a data abort: `ISV` (bit 24), `SAS` (bits 23:22 → size 1/2/4/8), `SRT` (bits 20:16 → GPR number), `WnR` (bit 6 → write-not-read). `ISV=0` is reported as unsupported (Linux's GIC/virtio accesses are plain loads/stores that set `ISV=1`).
3. Builds a `struct mmio_access { u64 ipa; u64 offset; u8 size; bool is_write; u64 data; }` and looks up a registered device on a small static **MMIO bus** (`mmio_bus_lookup(ipa)`), keyed by `[base, base+len)` IPA ranges.
4. For a **write**, copies the source GPR (`SRT`) into `acc.data` before calling the handler; for a **read**, calls the handler then writes `acc.data` back into the destination GPR (`SRT`), honouring `xzr` (`SRT==31`).
5. Advances `regs->elr_el2 += 4` and returns; the existing `el1_sync_handler` eret-back path (vmexit_asm.S, lines 122–148) restores guest regs from `g_vm.vcpu.regs` and erets. **No assembly change is required** — `el1_sync_handler` already saves all GPRs into `g_vm.vcpu.regs` before `handle_exit` and reloads them all (including the patched `ELR` and `SRT` register) afterwards.

The MMIO bus is a fixed-size static array of `struct mmio_region { u64 base; u64 len; mmio_handler_t handler; void *ctx; }`. The handler signature is `int (*mmio_handler_t)(struct mmio_access *acc, void *ctx)` returning `0` on success, non-zero on error. M3.2 (vGIC) and M3.3 (virtio) register their devices on this bus via `mmio_bus_register(base, len, handler, ctx)`; the M3.1 deliverable registers a **temporary scaffold** handler over the GICD range (`0x08000000`, 64 KB) that records and prints the decoded access, proving decode + dispatch. The scaffold is deleted in M3.2.

**Tech Stack:** C11 freestanding (`-ffreestanding -nostdlib -mgeneral-regs-only -mstrict-align -Werror -O2 -g`), aarch64; printk supports only `%s %c %d %u %x %lx %%`. Single `g_vm` / single vCPU. New files compiled via `hypervisor/arch/arm64/Makefile` `arch-objs`.

## ESR_EL2 ISS layout for Data Abort (EC = 0x24), for reference

For a Data Abort taken to EL2 (lower-EL, EC `0x100100` = `0x24`), `ESR_EL2[24:0]` is the ISS:

| Field | Bits | Meaning |
|---|---|---|
| `ISV`  | 24    | Instruction Syndrome Valid. `1` ⇒ `SAS`/`SRT`/`WnR` are valid (the supported path). |
| `SAS`  | 23:22 | Access size: `00`=byte(1), `01`=half(2), `10`=word(4), `11`=double(8). |
| `SSE`  | 21    | Sign-extend (not needed: handler returns raw bytes; sign handled by guest). |
| `SRT`  | 20:16 | Transfer register number (the GPR, 0–31; 31 = `xzr`/`wzr`). |
| `SF`   | 15    | 0=32-bit reg, 1=64-bit reg (not needed for byte-copy semantics). |
| `WnR`  | 6     | Write-not-Read: `1`=store(write), `0`=load(read). |
| `DFSC` | 5:0   | Data Fault Status Code (e.g. `0b000111` = translation fault L3). Logged on no-handler. |

IPA reconstruction: `ipa = (HPFAR_EL2[43:4] << 8) | (FAR_EL2 & 0xFFF)`. The `<< 8` converts the HPFAR page-frame field (which holds `IPA[47:12]` in bits `[43:4]`, i.e. IPA right-shifted by 12 then left-shifted by 4) back to a byte address: `(HPFAR & 0xFFFFFFFFFFF0) << 8` yields `IPA & ~0xFFF`.

**Files:**
- Create: `hypervisor/arch/arm64/vmexit/mmio.h`

- [ ] **Step 1: Write the full header**

Create `hypervisor/arch/arm64/vmexit/mmio.h`:

```c
/* SPDX-License-Identifier: TBD */
#ifndef HV_ARM64_MMIO_H
#define HV_ARM64_MMIO_H

#include <types.h>
#include <vm.h>

/*
 * A decoded Stage-2 MMIO access handed to a device handler.
 *
 *   ipa      - faulting guest IPA (byte address, FAR offset already merged)
 *   offset   - ipa - region base; what most device handlers actually use
 *   size     - access width in bytes: 1, 2, 4, or 8
 *   is_write - true for a store (guest -> device), false for a load
 *   data     - WRITE: value the guest stored (filled in before the handler).
 *              READ:  value the device returns (handler fills it in).
 */
struct mmio_access {
    u64  ipa;
    u64  offset;
    u8   size;
    bool is_write;
    u64  data;
};

/*
 * Device handler. Receives the decoded access and the ctx registered with the
 * region. Returns 0 on success, non-zero to signal an unhandled/failed access
 * (which the abort path treats like "no handler": diagnostic + park).
 */
typedef int (*mmio_handler_t)(struct mmio_access *acc, void *ctx);

/*
 * Register a device over the IPA range [base, base + len). Later milestones
 * (M3.2 vGIC, M3.3 virtio) call this. Returns 0 on success, -1 if the bus is
 * full. Ranges are not checked for overlap (single-author bus, M3.x).
 */
int mmio_bus_register(u64 base, u64 len, mmio_handler_t handler, void *ctx);

/*
 * Stage-2 data-abort entry point (EC = 0x24). Decodes ESR_EL2 ISS + HPFAR/FAR,
 * dispatches to a registered handler, plumbs the transfer register, and on
 * success advances regs->elr_el2 past the faulting instruction.
 * Returns 0 if handled (caller erets back), non-zero if unhandled.
 */
int mmio_handle_data_abort(struct vcpu_regs *regs, u64 esr);

#endif /* HV_ARM64_MMIO_H */
```

**Files:**

- [ ] **Step 1: Write the file skeleton with the static bus + register/lookup**

Create `hypervisor/arch/arm64/vmexit/mmio.c`:

```c
/* SPDX-License-Identifier: TBD */
#include <types.h>
#include <printk.h>
#include <vm.h>
#include "mmio.h"

/*
 * Fixed-size MMIO bus. M3.x needs only a handful of regions:
 * GICD, GICR, and one or two virtio-mmio frames. 8 is ample headroom.
 */
#define MMIO_MAX_REGIONS 8

struct mmio_region {
    u64            base;
    u64            len;
    mmio_handler_t handler;
    void          *ctx;
};

static struct mmio_region mmio_regions[MMIO_MAX_REGIONS];
static u32 mmio_region_count;

int mmio_bus_register(u64 base, u64 len, mmio_handler_t handler, void *ctx)
{
    if (mmio_region_count >= MMIO_MAX_REGIONS)
        return -1;

    mmio_regions[mmio_region_count].base    = base;
    mmio_regions[mmio_region_count].len     = len;
    mmio_regions[mmio_region_count].handler = handler;
    mmio_regions[mmio_region_count].ctx     = ctx;
    mmio_region_count++;
    return 0;
}

static struct mmio_region *mmio_bus_lookup(u64 ipa)
{
    for (u32 i = 0; i < mmio_region_count; i++) {
        struct mmio_region *r = &mmio_regions[i];
        if (ipa >= r->base && ipa < r->base + r->len)
            return r;
    }
    return NULL;
}
```

### Task 3: Implement ISS decode + IPA reconstruction + dispatch in `mmio.c`

**Files:**
- Modify: `hypervisor/arch/arm64/vmexit/mmio.c`

- [ ] **Step 1: Append the ISS field macros and the data-abort handler**

Append to `hypervisor/arch/arm64/vmexit/mmio.c` (after `mmio_bus_lookup`):

```c
/* ESR_EL2 ISS fields for a Data Abort (EC = 0x24). */
#define ISS_ISV(iss)  (((iss) >> 24) & 0x1U)   /* Instruction Syndrome Valid */
#define ISS_SAS(iss)  (((iss) >> 22) & 0x3U)   /* Access size 00..11 -> 1/2/4/8 */
#define ISS_SRT(iss)  (((iss) >> 16) & 0x1FU)  /* Transfer register 0..31 */
#define ISS_WNR(iss)  (((iss) >> 6)  & 0x1U)   /* Write not Read */
#define ISS_DFSC(iss) ((iss) & 0x3FU)          /* Data Fault Status Code */

/* SAS (00,01,10,11) -> access size in bytes (1,2,4,8). */
static u8 mmio_sas_to_bytes(u32 sas)
{
    return (u8)(1U << sas);
}

/* Read FAR_EL2 / HPFAR_EL2 and reconstruct the faulting guest IPA. */
static u64 mmio_faulting_ipa(void)
{
    u64 far, hpfar;
    asm volatile("mrs %0, far_el2"   : "=r"(far));
    asm volatile("mrs %0, hpfar_el2" : "=r"(hpfar));
    /*
     * HPFAR_EL2[43:4] = IPA[47:12]. (hpfar & 0xFFFFFFFFFFF0) << 8 yields the
     * 4 KB-aligned IPA; merge the page offset from FAR_EL2[11:0].
     */
    return ((hpfar & 0xFFFFFFFFFFF0ULL) << 8) | (far & 0xFFFULL);
}

int mmio_handle_data_abort(struct vcpu_regs *regs, u64 esr)
{
    u32 iss = (u32)(esr & 0x01FFFFFFU);

    if (ISS_ISV(iss) == 0U) {
        /* No instruction syndrome: would require fetching+decoding the guest
         * instruction. Linux GIC/virtio accesses are simple loads/stores with
         * ISV=1, so we report this as unsupported for M3.x. */
        printk("[hv] MMIO: ISV=0 unsupported, ESR=0x%lx ELR=0x%lx\n",
               esr, regs->elr_el2);
        return -1;
    }

    u64 ipa = mmio_faulting_ipa();
    struct mmio_region *r = mmio_bus_lookup(ipa);
    if (r == NULL)
        return -1;   /* caller logs DFSC + parks */

    u32 srt = ISS_SRT(iss);

    struct mmio_access acc;
    acc.ipa      = ipa;
    acc.offset   = ipa - r->base;
    acc.size     = mmio_sas_to_bytes(ISS_SAS(iss));
    acc.is_write = (ISS_WNR(iss) != 0U);
    acc.data     = 0;

    if (acc.is_write) {
        /* Source GPR -> data. SRT=31 is the zero register. */
        acc.data = (srt == 31U) ? 0ULL : regs->x[srt];
    }

    if (r->handler(&acc, r->ctx) != 0)
        return -1;

    if (!acc.is_write && srt != 31U) {
        /* Load: device result -> destination GPR. */
        regs->x[srt] = acc.data;
    }

    /* Advance past the faulting load/store; el1_sync_handler erets back. */
    regs->elr_el2 += 4;
    return 0;
}
```

### Task 4: Add the temporary scaffold device (`mmio_scaffold.c`)

**Files:**
- Create: `hypervisor/arch/arm64/vmexit/mmio_scaffold.c`

It returns `0` for reads (data stays 0 — the guest GIC probe sees zeroes) so the guest continues instead of parking. **Deleted in M3.2** when the real `VirtualGicd` registers over the same range.

- [ ] **Step 1: Write the scaffold**

Create `hypervisor/arch/arm64/vmexit/mmio_scaffold.c`:

```c
/* SPDX-License-Identifier: TBD */
/*
 * M3.1 TEMPORARY scaffold device. Registered over the GICD MMIO range to prove
 * the Stage-2 data-abort decode + MMIO dispatch path delivers correct
 * {addr, size, direction, data} to a handler. REMOVE in M3.2: the real
 * vGICv3 distributor emulation registers over this same range.
 */
#include <types.h>
#include <printk.h>
#include <board.h>
#include "mmio.h"

/* QEMU virt GICD frame: 0x08000000, 64 KB. */
#define SCAFFOLD_GICD_BASE  BOARD_GIC_DIST_BASE
#define SCAFFOLD_GICD_LEN   0x00010000ULL

static int scaffold_handler(struct mmio_access *acc, void *ctx)
{
    (void)ctx;

    if (acc->is_write) {
        printk("[hv] MMIO scaffold: WRITE ipa=0x%lx off=0x%lx size=%u data=0x%lx\n",
               acc->ipa, acc->offset, (unsigned)acc->size, acc->data);
    } else {
        /* Read-as-zero: the scaffold has no real registers. */
        acc->data = 0;
        printk("[hv] MMIO scaffold: READ  ipa=0x%lx off=0x%lx size=%u -> 0x%lx\n",
               acc->ipa, acc->offset, (unsigned)acc->size, acc->data);
    }
    return 0;
}

void mmio_scaffold_init(void)
{
    if (mmio_bus_register(SCAFFOLD_GICD_BASE, SCAFFOLD_GICD_LEN,
                          scaffold_handler, NULL) != 0)
        printk("[hv] MMIO scaffold: bus full, registration failed\n");
    else
        printk("[hv] MMIO scaffold: registered GICD range 0x%lx len 0x%lx\n",
               (unsigned long)SCAFFOLD_GICD_BASE,
               (unsigned long)SCAFFOLD_GICD_LEN);
}
```

**Open risks flagged in the plan:**
1. **GICR not covered by the scaffold.** The scaffold backs only the 64 KB GICD frame; the guest may take a later EC `0x24` at the GICR frame (`0x080A0000`). Task 8 Step 3 calls this out as expected, not a regression — M3.2 backs GICR. If a cleaner single-run demo is desired, the scaffold range could be widened, but that muddies the M3.2 handoff, so it is intentionally left narrow.
2. **`ISV=0` is unsupported.** If a real Linux build emits a GIC/virtio access that sets `ISV=0` (e.g. an unusual addressing mode or a load/store-pair), it lands in the unsupported path and parks. Mitigation noted: ISS-valid simple loads/stores are the overwhelming norm for MMIO; full instruction decode is deferred (the reference Rust hv keeps a fallback decoder, which a future task could port if needed).
3. **HCR_EL2 trap scope.** M3.1 assumes the GICD access already traps to EL2 as a Stage-2 data abort because the GICD IPA is unbacked in Stage-2 (the M3.0 design). If a future Stage-2 change accidentally maps the GICD frame, the abort would not fire and the scaffold would never be hit — the run observation in Task 8 is the guard against that.
4. **`-Wimplicit-fallthrough` form.** The `case 0x24:` fall-through relies on a comment or `__attribute__((fallthrough))`; Task 6 Step 3 verifies which the toolchain accepts and the build stays `-Werror`-clean either way.
5. **`vm.c` include depth.** The relative include from `hypervisor/common/vm/vm.c` to `mmio.h` is verified at build time (Task 7 Step 3); the exact `../` depth is adjusted if the compiler reports it, with the canonical path noted.
