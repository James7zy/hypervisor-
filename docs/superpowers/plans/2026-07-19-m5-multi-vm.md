# M5 — Multi-VM Foundation Implementation Plan

> **Status:** Ready for execution.

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

> **Upstream assumptions:** M3.5 is merged and boot-verified: `-smp 2` Linux with
> 2 vCPUs statically pinned, per-CPU state via `TPIDR_EL2` → `percpu[id].cur_vcpu`
> ([[../../adr/0013-smp-per-cpu-tpidr-guest-driven-bringup]]), guest-driven PSCI
> `CPU_ON`, SGI virtualization, printk spinlock. The PL011 is a Stage-2
> passthrough to the guest; EL2 printk shares it cooperatively. vGIC dist/redist
> state lives in file-statics `g_vgicd` / `g_vgicr[NR_CPUS]` (`vgic_v3_mmio.c`);
> Stage-2 tables are file-statics `l1_table` / `l2_dev` (`stage2.c`).

**Goal:** Two unmodified Linux guests, statically partitioned 2+2 on 4 pCPUs,
each with its own Stage-2/VMID, vGIC, and vuart, both reaching interactive
shells over one physical UART with Ctrl-T input-focus switching.
Full design: `docs/superpowers/specs/2026-07-19-m5-multi-vm-design.md`.

**Observable DoD:** `-smp 4 -m 4G` run boots both guests to `~ #`; Ctrl-T
switches input; `/sys/devices/system/cpu/online` = `0-1` in each VM;
`make test` green including the new dual-SVM scenario.

**Branches:** one per slice, merged after its gate passes:
`m5-slice1-vm-objectification` → `m5-slice2-vuart` → `m5-slice3-vm1-online`.

**Per-slice gate (all three):** `make` zero warnings; `make test` green;
manual `LINUX_IMAGE=… LINUX_INITRD=… make run` boots single-VM SMP Linux to an
interactive `~ #` (until slice 3 makes it dual-VM).

**Header-dependency warning:** the Makefile does not track header deps — run
`make clean` after every header edit (`vm.h`, `percpu.h`, `board.h`,
`vm_config.h`), or stale `.o`s relink with old struct layouts and fail weirdly.

- [ ] `vgic_sgi.c`: sender resolves targets **within the caller's VM**:

## Slice 2 — EL2 owns the UART; VM0 on a vuart (`m5-slice2-vuart`)

> Still one VM. The console path changes; everything else must not.

### Task 2.1 — `hypervisor/dm/vuart.{c,h}`: PL011 model

**Files:** Create `hypervisor/dm/vuart.c`, `hypervisor/dm/vuart.h`; modify
`Makefile` (add `hypervisor/dm/vuart.o` to the object list), `vm.h` (embed
`struct vuart vuart;` in `struct vm`; forward-include `dm/vuart.h`)

- [ ] `vuart.h`:

```c
#ifndef HV_DM_VUART_H
#define HV_DM_VUART_H
#include <types.h>

#define VUART_RX_FIFO 16U   /* PL011 FIFO depth */

struct vuart {
    u8  rx_buf[VUART_RX_FIFO];
    u32 rx_head, rx_tail;        /* head==tail → empty */
    u32 imsc, ris;               /* interrupt mask / raw status      */
    u32 ibrd, fbrd, lcr_h, cr, ifls;  /* stored, no modelled effect  */
};

struct vm;
/* Register the shared PL011 IPA region on the MMIO bus (call once). */
void vuart_bus_init(void);
/* EL2 RX path: push one received char into this VM's vuart and raise its
 * virtual RX interrupt (SPI 33) if unmasked. */
void vuart_rx(struct vm *vm, u8 ch);
#endif
```

- [ ] `vuart.c` — the MMIO handler resolves the VM via
  `current_vcpu()->owner` (one global registration at
  `BOARD_UART_BASE`, length `0x1000`). Register map (offsets per PL011 TRM;
  Linux touches exactly these — DTS is `arm,pl011` + `arm,primecell`):

```c
/* reads */
case 0x000: /* DR  */ pop rx ring (empty → 0); if ring now empty ris &= ~RXIS;
case 0x018: /* FR  */ (ring empty ? FR_RXFE : 0) | FR_TXFE;   /* TX never full */
case 0x03C: /* RIS */ ris;
case 0x040: /* MIS */ ris & imsc;
case 0x024/0x028/0x02C/0x030/0x034/0x038: return stored reg;
case 0xFE0..0xFFC: /* AMBA PeriphID/CellID — REQUIRED for amba probe */
    static const u8 pl011_id[8] = {0x11,0x10,0x14,0x00,0x0D,0xF0,0x05,0xB1};
    return pl011_id[(off - 0xFE0) >> 2];
/* writes */
case 0x000: /* DR   */ console_putc((char)data);      /* serialized TX */
case 0x038: /* IMSC */ imsc = data;
case 0x044: /* ICR  */ ris &= ~data;
case 0x024/0x028/0x02C/0x030/0x034: store;            /* no effect */
default: ignore writes, read-as-zero;                 /* incl. DMACR */
```

  `RXIS` = bit 4 (RXIM position). `vuart_rx()` = push (drop char if ring
  full), `ris |= RXIS`, and if `imsc & RXIS` →
  `vgic_inject_spi(&vm->vcpu[0], BOARD_PL011_IRQ)`.
- [ ] TX serialization: add to `lib/print.c` a public
  `void console_putc(char c)` that takes `print_lock` around `uart_putc`
  (declare in `include/printk.h`). vuart TX and printk now share one lock —
  guest and EL2 output can interleave by line but never corrupt a character.

### Task 2.2 — Stage-2: unmap the PL011; EL2 takes the RX interrupt

**Files:** Modify `hypervisor/arch/arm64/mmu/stage2.c`,
`hypervisor/debug/uart_pl011.c` + `include/uart.h`,
`hypervisor/arch/arm64/irq/irq_handler.c`, `hypervisor/common/vm/vm.c`

- [ ] `stage2.c`: punch out the PL011's 2 MB L2 entry exactly like the GIC's:

```c
    u32 uart_l2_idx = (u32)(BOARD_UART_BASE >> 21);   /* 0x09000000 >> 21 = 72 */
    l2_dev[vm->id][uart_l2_idx] = 0;   /* invalid → trap → vuart */
```

  Safe because the guest DTS declares **no other device** in
  `0x09000000..0x091FFFFF` (verified: dts nodes are cpus/psci/timer/pl011/
  clock/gic only). Any stray access faults loudly on the MMIO bus — that is
  the fail-stop we want (ADR-0007).
- [ ] `uart_pl011.c`: add `void uart_rx_irq_enable(void)` → sets
  `IMSC = (1U<<4) | (1U<<6)` (RXIM + RTIM receive-timeout so sub-FIFO-depth
  input still interrupts). Call it from `vm_run()` after `vgic_restore`
  (pCPU0 owns the RX SPI). The physical SPI 33 GICD enable + route-to-pCPU0
  already exist from M3.5 — unchanged.
- [ ] `irq_handler.c` PL011 branch becomes the EL2 RX pump:

```c
    } else if (intid == BOARD_PL011_IRQ) {
        int c;
        while ((c = uart_getc()) >= 0)
            vuart_rx(&vm[console_focus], (u8)c);   /* focus == 0 this slice */
        gic_priority_drop(intid);
        gic_deactivate(intid);   /* FIFO drained; QEMU re-asserts on new data */
    }
```

  `console_focus` is a `u32` in `vuart.c` (exported), fixed 0 until slice 3.
  Note the physical SPI is now **deactivated** (EL2 completed the whole RX);
  the old leave-Active trick was for the passthrough guest ISR and no longer
  applies.
- [ ] `vm_init()` (or `hypervisor_main`) calls `vuart_bus_init()` once,
  after `vgicv3_mmio_init()`.
