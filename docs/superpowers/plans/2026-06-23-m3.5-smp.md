# M3.5 — SMP (2-vCPU Linux, static 1:1 pinning) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

> **Upstream assumptions (state up front):** This plan builds on **M3.4** (merged):
> a single `-smp 1` Linux guest booting to a busybox shell over the PL011
> passthrough, modeled as a single global `g_vm` with one `g_vm.vcpu`
> ([[../../adr/0002-single-global-vm-single-vcpu]]). The exception-entry asm reaches
> the guest frame via `adrp x0, g_vm`
> ([[../../adr/0003-asm-c-vcpu-offset-coupling]]). The vtimer PPI is
> hardware-forwarded ([[../../adr/0001-vtimer-hardware-forwarding]]); EL2 owns the
> physical GICv3 ([[../../adr/0012-physical-gicv3-ownership]]); the vGICv3 GICD/GICR
> is trap-and-emulate, cpu0 only ([[../../adr/0010-vgic-scope-cpu0-lr0-group1]]).
> PSCI `CPU_ON` currently returns `NOT_SUPPORTED` (M3 stub in `psci.c`).

**Goal:** Boot an `-smp 2` Linux guest so its secondary CPU comes online (two
vCPUs, static 1:1 pinned to two pCPUs, **no scheduler**, `NR_CPUS=2`). Full design
and rationale: `docs/superpowers/specs/2026-06-23-m3.5-smp-design.md`.

**Observable DoD:** `make run` with `-smp 2` prints `CPU1: Booted secondary
processor …` / `smp: Brought up 1 node, 2 CPUs`, and `nproc` shows **2** at the
busybox prompt. The SGI/IPI path is a **non-blocking strong-verification** step,
not a gate.

---

## Slice ordering rationale

The riskiest change is the exception-entry asm (4 `adrp x0, g_vm` sites across
`vmexit_asm.S` and `irq_handler_asm.S`). **Slice 1 isolates it as a pure,
behavior-preserving UP refactor and lands as its own first commit.** Concurrency
(Slice 5, SGI) lands last, after everything else is proven, so a failure there is
localized.

---

## Slice 1 — per-CPU foundation (UP, behavior unchanged) — OWN COMMIT

> Pure refactor. Single-core Linux must still boot to `~ #`. No concurrency yet.

- [ ] **Task 1.1 — `percpu.h` / `percpu.c`.** Add `hypervisor/arch/arm64/include/percpu.h`
  (or alongside existing per-arch includes) with:
  - `#define NR_CPUS 2`
  - `#define PERCPU_CUR_VCPU 0` (cur_vcpu is the first field)
  - `struct percpu { struct vcpu *cur_vcpu; u32 cpu_id; volatile u32 online; /* stack base etc. */ };`
  - `_Static_assert(offsetof(struct percpu, cur_vcpu) == PERCPU_CUR_VCPU, "asm offset");`
  - `static inline struct vcpu *current_vcpu(void)` reading `TPIDR_EL2` →
    `((struct percpu *)tpidr)->cur_vcpu`.
  - `percpu.c`: `struct percpu percpu[NR_CPUS];`
- [ ] **Task 1.2 — CPU0 sets `TPIDR_EL2`.** In `hypervisor_main` (or `vm_init`),
  set `percpu[0].cur_vcpu = &g_vm.vcpu` (or `&vcpu[0]` after Task 1.4 renames),
  `percpu[0].cpu_id = 0`, and `msr tpidr_el2, &percpu[0]` **before** the first
  `vcpu_run`.
- [ ] **Task 1.3 — rewrite the 4 asm sites.** In `vmexit_asm.S` (lines ~91, ~129)
  and `irq_handler_asm.S` (lines ~21, ~57), replace
  `adrp x0, g_vm` / `add x0, x0, :lo12:g_vm` with
  `mrs x0, tpidr_el2` / `ldr x0, [x0, #PERCPU_CUR_VCPU]`. Update the comments
  (no longer "first field of first field = same address as g_vm").
- [ ] **Task 1.4 — (optional, can defer to Slice 4) widen the vCPU storage.** Keep
  `g_vm` for now but make the per-CPU pointer the single source of truth in asm.
  Renaming `g_vm.vcpu` → `vcpu[NR_CPUS]` may stay in Slice 4 to keep Slice 1 a
  minimal diff — your call, but Slice 1 must not regress UP boot.
- [ ] **Verify 1:** `make` zero warnings; `_Static_assert` compiles; `readelf -h`
  entry `0x40080000`; `make run` (still `-smp 1`) boots to `~ #` and `ls`/`uname`
  work. **Commit this slice alone.**

## Slice 2 — wake pCPU1 (no guest yet)

- [ ] **Task 2.1 — spinlock.** Add `hypervisor/.../spinlock.h`: a minimal
  ticket (or `LDAXR/STXR` test-and-set) spinlock with `dmb/dsb` barriers,
  `spin_lock` / `spin_unlock`. Not used until printk/SGI but introduce it here.
- [ ] **Task 2.2 — `secondary_entry` in `head.S`.** Delete `secondary_park`. Add a
  `secondary_entry` label (reached at EL2 with `x0 = context_id` from QEMU PSCI):
  1. set `SP_EL2` from a per-CPU stack (static stack array indexed by `context_id`);
  2. `VBAR_EL2 = hv_vectors`; `msr tpidr_el2, &percpu[context_id]`;
  3. mask DAIF, `dsb/isb`;
  4. `mov x0, context_id; bl secondary_main`.
- [ ] **Task 2.3 — `secondary_main(u32 id)` (C).** Per-CPU EL2 init in order:
  `ICC_SRE_EL2` enable; GICR wake (`GICR_WAKER` ProcessorSleep/ChildrenAsleep) +
  enable kick-SGI INTID and vtimer PPI (INTID 27) on this core's GICR; arm vtimer;
  `CNTVOFF_EL2 = 0`. Then `percpu[id].cpu_id = id; dmb; percpu[id].online = 1;`
  then `for(;;) wfi();` (temporary — replaced in Slice 3).
- [ ] **Task 2.4 — CPU0 fires `CPU_ON` + handshake (temporary driver).** Add a
  helper that issues `smc PSCI_CPU_ON(entry=secondary_entry_phys, ctx=1)` and
  spins on `percpu[1].online` with a timeout print. For Slice 2, call it once from
  `hypervisor_main` after CPU0 init to prove the path (this call moves into
  `psci_handle` in Slice 4).
  - kick-SGI INTID and `secondary_entry` physical address belong in `board.h` /
    a symbol; define `BOARD_KICK_SGI` and resolve `secondary_entry` PA.
- [ ] **Verify 2:** `make run` prints `[hv] pCPU1 online` and CPU0's handshake
  message; UP guest still boots (CPU0 path untouched).

## Slice 3 — vCPU1 spins a guest (smoke)

- [ ] **Task 3.1 — widen vCPU storage** (if not done in 1.4): `struct vcpu
  vcpu[NR_CPUS]` (or keep them inside `struct vm`). vCPU1 shares vCPU0's Stage-2
  table / VMID.
- [ ] **Task 3.2 — per-CPU guest entry.** In `secondary_main`, after init:
  `stage2_activate(&vcpu[id])` **then** `vgic_restore(&vcpu[id])`, set `HCR_EL2`,
  `isb`, then `vcpu_run(&vcpu[id])`. For the smoke test, temporarily seed vCPU1's
  regs to a known stub (or the same entry as vCPU0) just to confirm entry works.
  - **Ordering constraint:** Stage-2 activate **must** precede `vgic_restore`.
- [ ] **Task 3.3 — `VMPIDR_EL2`.** Set per-vCPU virtual MPIDR: vCPU0→Aff0=0,
  vCPU1→Aff0=1, in each core's bring-up.
- [ ] **Verify 3:** both cores enter the guest without crashing (transient — this
  entry becomes guest-driven in Slice 4). Remove any stub seeding afterward.

## Slice 4 — wire guest-driven `CPU_ON`

- [ ] **Task 4.1 — DTS + QEMU.** `guest/qemu_virt.dts`: add symmetric
  `cpu@1 { device_type="cpu"; compatible="arm,cortex-a72"; reg=<0x1>;
  enable-method="psci"; };`. Confirm `psci { method="hvc"; }` (already present).
  `scripts/run-qemu.sh`: `-smp 1` → `-smp 2`. `make guest` to recompile the DTB.
- [ ] **Task 4.2 — `psci_handle` `CPU_ON`.** Replace the `NOT_SUPPORTED` stub:
  1. read `target=x1`, `entry=x2`, `ctx=x3`;
  2. map `target` affinity → vCPU index; if not in {0,1} → `INVALID_PARAMETERS`;
  3. fill `vcpu[1].regs`: `elr_el2=entry`, `x[0]=ctx`, `x[1..3]=0`,
     `spsr_el2=0x3C5`, `hcr_el2` like vCPU0;
  4. issue physical `smc CPU_ON(entry=secondary_entry, ctx=index)`;
  5. spin on `percpu[index].online` (timeout);
  6. return `PSCI_RET_SUCCESS`.
  - Move the temporary Slice-2 CPU_ON call out of `hypervisor_main` — bring-up is
    now triggered by the guest.
- [ ] **Task 4.3 — `secondary_main` runs the real vCPU1.** Drop the smoke stub; the
  vCPU1 regs are now authored by `psci_handle` before `CPU_ON`. `secondary_main`
  ends in `vcpu_run(&vcpu[index])`.
- [ ] **Verify 4 (headline):** `make run` shows `CPU1: Booted secondary
  processor …` and `smp: Brought up 1 node, 2 CPUs`; `nproc` = 2 at the shell.

## Slice 5 — SGI / IPI (concurrency lands last)

- [ ] **Task 5.1 — trap `ICC_SGI1R_EL1`.** Set `ICH_HCR_EL2.TC = 1` per vCPU; add
  the EL2 trap decode for the `ICC_SGI1R_EL1` system-register write in the sysreg
  trap path. Decode target affinity list + vINTID.
- [ ] **Task 5.2 — shared SGI pending bitmap.** Per-vCPU pending-SGI bitmap
  (16 SGIs) in `struct vcpu` (or `percpu`); writes guarded by the **SGI spinlock**.
- [ ] **Task 5.3 — physical kick-SGI.** On `ICC_SGI1R` trap: set the target vCPU's
  pending bits, then issue a **physical** SGI (`BOARD_KICK_SGI`) to the target
  pCPU via the real `ICC_SGI1R_EL1`.
- [ ] **Task 5.4 — drain on the target.** In `el2_irq_handler`, add the kick-SGI
  branch: drain the pending bitmap (SGI spinlock), `vgic_inject_sw` each pending
  vINTID into this core's LR, then priority-drop **and deactivate** the kick-SGI.
  Also change the existing hard-coded `&g_vm.vcpu` injections to `current_vcpu()`.
- [ ] **Task 5.5 — printk spinlock.** Guard `printk`/UART output with the spinlock
  to stop cross-core interleaving.
- [ ] **Verify 5 (strong, non-blocking):** `/proc/interrupts` IPI counts grow;
  two `yes > /dev/null &` loads show both pCPUs' EL2 tick counters advancing.
